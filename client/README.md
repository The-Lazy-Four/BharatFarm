# BharatFarm Frontend Architecture

## Overview
Modular React + Vite + TypeScript frontend client designed with strict domain feature separation.

## Structure
- App Bootstrap (`/src/app`)
- Feature Modules (`/src/features`)
- UI Components (`/src/components`)
- Global Services (`/src/services`)
- Context Providers (`/src/context`)

## Feature Modules
- `krishibot`: Multilingual AI Agronomist Assistant
- `scanner`: Plant Leaf Health & Disease Scanner
- `marketplace`: Direct Agri-Commerce Trading
- `weather`: Hyperlocal Weather Advisory
- `groupbuying`: Community Input & Wholesale Pooling
- `schemes`: Government Agri-Welfare & Credit Assessment
