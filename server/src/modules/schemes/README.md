# Schemes Backend Module

## Purpose
Government schemes information & loan eligibility assessment backend service.

## Endpoints
- `GET /api/schemes` - List available central & state government schemes.
- `POST /api/schemes/check-eligibility` - Check scheme eligibility against land & farmer profile.
- `POST /api/schemes/loan-assessment` - Generate BharatFarm Credit Assessment score.
