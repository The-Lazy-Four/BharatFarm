# Marketplace Backend Module

## Purpose
Direct Agri-Commerce trading backend for farmers and buyers (B2B / D2C).

## Endpoints
- `GET /api/marketplace/listings` - List available products.
- `GET /api/marketplace/listings/:id` - Fetch product details.
- `POST /api/marketplace/listings` - Create new listing.
- `PATCH /api/marketplace/listings/:id` - Update listing details.
- `DELETE /api/marketplace/listings/:id` - Remove listing.
