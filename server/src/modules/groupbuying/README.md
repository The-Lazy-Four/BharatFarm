# Group Buying Backend Module

## Purpose
Community input pooling for fertilizer/seed wholesale price reduction.

## Endpoints
- `GET /api/groupbuying` - List active group buying pools.
- `GET /api/groupbuying/:id` - Fetch pool details.
- `POST /api/groupbuying/:id/join` - Join an active bulk purchase pool.
